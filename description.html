Copy this profile’s mail to Nextcloud or Google Drive, then restore it into an empty profile. Cloud Backup encrypts the mailboxes in the current Thunderbird profile and stores them in a ThunderbirdBackup folder on Nextcloud or Google Drive. The passphrase never leaves this computer. A lost passphrase makes the snapshots unreadable. Key features:
  • Nextcloud (app password) or Google Drive.
  • Mail is encrypted before it is uploaded. The passphrase is not saved on disk.
  • The cloud keeps the three newest snapshots.
  • After you unlock storage, new mail is copied about once a minute while Thunderbird is open.
  • Restore writes the mailboxes into the profile you have open. Do that in an empty profile.
Installation:
  1. In Thunderbird, open the menu and choose Add-ons and Themes.
  2. Click the gear icon and choose Install Add-on From File…, then select the .xpi. Or type Cloud Backup in the search field, open this add-on, and choose Add to Thunderbird.
  3. When Thunderbird asks for access, choose Add.
This add-on needs Thunderbird 128 or newer. Install it in a profile that already contains mail. An empty profile has nothing to back up. Open Mail backup Click the Mail backup toolbar button, or open the add-on card in Add-ons and Themes and choose its preferences. The page shows the profile folder, the Thunderbird version, and how much mailbox data is on disk. Connect Nextcloud
  1. Under Destination, choose Nextcloud.
  2. Enter the server URL, such as https://cloud.example, your user name, and an app password from Nextcloud.
  3. Choose Save connection.
The add-on stores files in ThunderbirdBackup on that account. Connect Google Drive
  1. Under Destination, choose Google Drive.
  2. In Google Cloud, create an OAuth client and paste its client id into OAuth client id.
  3. Copy the redirect URI shown on the page and add that exact URI to the client in Google Cloud.
  4. Choose Save connection, then Sign in with Google.
The add-on stores files in a ThunderbirdBackup folder on that Drive account. Unlock storage
  1. Type a passphrase and choose Unlock storage.
  2. The first time, that passphrase creates the encrypted storage. Later, the same passphrase opens it. The status line shows a key fingerprint when the passphrase is accepted.
The passphrase is kept only for this Thunderbird session. After a restart, type it again before a backup or a restore. If you lose it, the snapshots cannot be read. Back up Choose Back up. The log reports the snapshot id when new mail was copied, or that nothing changed. A mailbox is included after it has been idle for about a minute, so a message you are still receiving waits until that pause. While the passphrase is unlocked, the same copy also runs about once a minute. Refresh list loads the snapshots. The cloud keeps the three newest. Check a snapshot Select a snapshot and choose Verify. The log reports how many files and chunks that snapshot contains. Restore Restore into an empty profile, one that does not already hold the mail you want to keep.
  1. Install this add-on in that empty profile and connect the same cloud account.
  2. Unlock storage with the same passphrase.
  3. Select the snapshot and choose Restore into this profile. Confirm the prompt.
  4. When the log says the mailboxes were written, quit Thunderbird.
Saved passwords are swapped in when Thunderbird quits. On the next launch the add-on installs itself again in that profile. Open Thunderbird after the quit and the restored mail is there.
