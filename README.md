# Cloud Backup

Copy this profile’s mail to Nextcloud or Google Drive, then restore it into an empty profile. Cloud Backup encrypts the mailboxes before upload and stores them in a `ThunderbirdBackup` folder. The passphrase never leaves this computer. A lost passphrase makes the snapshots unreadable.

This add-on needs Thunderbird 128 or newer. Install it in a profile that already contains mail. An empty profile has nothing to back up.

## Install from a file

1. Download [`releases/cloud-backup-0.1.0.xpi`](releases/cloud-backup-0.1.0.xpi).
2. In Thunderbird, open the menu and choose **Add-ons and Themes**.
3. Click the gear icon and choose **Install Add-on From File…**.
4. Select the downloaded `.xpi` file.
5. When Thunderbird asks for access, choose **Add**.

## Install from add-on search

1. In Thunderbird, open the menu and choose **Add-ons and Themes**.
2. In the search field, type `Cloud Backup` and press Enter.
3. Open the result for this add-on, by Ilya Devin, and choose **Add to Thunderbird**.
4. When Thunderbird asks for access, choose **Add**.
